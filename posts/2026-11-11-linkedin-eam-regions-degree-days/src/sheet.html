Regions & Degree Days Cheat sheet
Turn daily temperatures into HDD / CDD and explain your energy and CO2e swings.

1. Why Degree Days

  • Link weather to energy use and resulting carbon emissions
  • Keep historical + actual Degree Days per Region (usually geographic)
  • Audience: admins + energy / emissions owners
  • Goal: DD factor in current + projected energy use

2. Reference Value

  • Outside temp where no heating or cooling is normally needed
  • Typical: 65°F (18.3°C); must be set, can be changed
  • Stored as Degree Day Reference Point on the Region

3. The formulas

Tavg = (Tmin + Tmax) / 2 CDD = MAX(Tavg - RefPoint, 0) -- summer severity HDD = MAX(RefPoint - Tavg, 0) -- winter severity
  • One of HDD / CDD is always 0; Tavg = Ref → both 0
  • Additive: sum or average over weeks, seasons

5. Regions screen (Record View)

  • Defines the Region (typically geographic)
  • Degree Day Reference Point
  • Scale: Fahrenheit / Celsius (all calcs use it)
  • Actual weather source: NCDC (NOAA) + Actual Temperatures URL

6. Historical Temperatures tab

  • Baseline: 366 records, one per day of year
  • Pre-populated with nulls; structure stays intact
  • Defaults: Day of Year 1–366, Month 1–12, Day 1–31
  • Load via Upload Utility; edit Min/Max → Avg, HDD, CDD recalc

7. Actual Temperatures tab

  • One record per unique date (list/detail)
  • User enters Date, Temp Minimum, Temp Maximum
  • System recalcs Average + HDD/CDD from Reference Point
  • Or collect offline (Excel) → Upload Utility

8. Getting actual data

  • Request one or more dates in a single call
  • GETWEATHER background job runs nightly for latest actuals
  • NCDC needs an 11-character Station ID
.../cdo-web/api/v2/data?stationid=GHCND:USW00013886

9. Known gotcha (EAM-13801)

  • Interface built in 2011 on XML; NCDC now JSON (API v2) only
  • Get Actual Temperatures link throws an error
  • Actual Temperatures URL must be re-formatted to current NCDC rules
  • Fallback: Upload Utility for actuals

Flow

Region + Ref→ 366 historical→ Daily actuals→ HDD / CDD→ Energy reports

Consultant tips

  1. Fix °F/°C before loading data
  2. Test GETWEATHER output early
  3. Upload Utility = safe fallback

Key points

  • Avg = (Min + Max) / 2
  • HDD or CDD, never both
  • Degree Days are additive
