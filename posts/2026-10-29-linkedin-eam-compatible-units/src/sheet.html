⚡ HxGN EAM Compatible Units CHEAT SHEET
Estimate utility projects from standard building blocks, then push the approved estimate straight into a work order. (Infor EAM 11.7 brief)

1. Key terms

  • CU Library record: template of labor, parts, tools, services (+ Child CUs)
  • CU Design Project: project flagged for CUs; many estimates
  • CU Estimate: work points + CUs → total cost
  • Work Point / Span (a length, e.g. a trench)

2. Setup before use

  • Screen Designer: show Available for CUs (Trades, Tools, Parts, Departments)
  • Show CU Standard Rate / Price fields
  • System Codes: CUAJ adjustments L0–L9, M0–M9, T0–T9
  • Activity Type codes (ACTP)
  • Status authorizations for PROJ, CUES, CULB (delivered for R5)

5. Action Type selection

  • Actions: Install, Remove, Abandon, Transfer
  • Only lines with the same action are costed
  • Blank action: labor/tools/services count for any action
  • Parts need an exact action match
  • Adjustment fields must match too (or be blank)

6. Estimate status (CUES)

Not Estimated→Estimated→Quoted→Approved
  • After Not Estimated, Work Points / Suppliers / CU tabs are protected
  • To edit: set back to Not Estimated, re-estimate

7. Worked example (Install)

Pole assembly = Pole + 2 Crossarm + Transformer
Labor 6 h × $40 = $240
Parts 500+2×200+1000 = $1,900
Tools 1.5 h × $100 = $150
Total = $2,290
Brief's example uses CU standard rates/prices.

8. Generate WO Activities

  • Only Design type in Approved status
  • Deletes existing deletable activities first
  • One activity per CU; creates Plan Labor, Parts, Plan Tools + material list
  • Services → hired labor lines
  • Same Activity Type → merged into one activity

10a. Estimator flow

CU Library→CU Design Project→CU Estimate + Work Points→Perform Estimation→Quote / Approve→Generate WO Activities

10b. Consultant tips

  1. Give every part line an action
  2. Set CU rates before estimating
  3. Use Activity Type to group work
  4. Keep a Template per job type

10c. Key points

  • Same job, same estimate
  • Design to WO in one click
  • FERC-ready cost split
