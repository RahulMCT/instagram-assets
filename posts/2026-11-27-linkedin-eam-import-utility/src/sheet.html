Octave Attune EAM (formerly HxGN EAM)
Import Utility Cheat sheet
Excel in, web services out: bulk-load EAM data from any screen's template.

1. What it is

  • Desktop tool that loads data into EAM from Excel (.xlsx) sheets
  • Use a template downloaded from EAM or a customer-supplied sheet
  • Rows = records, columns = fields; pushed in through web services
  • Guide audience: system administrators

2. Get the template

  • Any screen → right-click → Create Import Utility Template
  • .xlsx lands in your default download folder
  • Hide the option: clear Allow Creating Import Utility Template on the Users screen
  • Ignores the screen's INSERT / UPDATE / DELETE rights; not on list-only grids, generate, report or transactional screens

3. What happens behind it

  • EAM creates a Web Service Prompt record named 'UU' + last 4 of screen name (or user function if shorter than 5)
  • All screen fields added on the Fields tab
SSLOTS (Lots screen) → UULOTS Parts record view → WS row 1 Parts › Stores tab → WS row 2 (same prompt)
  • Same screen again = no new prompt; another tab = new Web Services row

4. The Excel sheet

  • Required Fields labels listed first, then the rest
  • Columns match the prompt's Fields tab
  • Unhide hidden rows to see XPath, R Entity, Field ID
  • Edit the prompt's Fields tab and re-download to shape your own template

5. Setup › Parameters

  • Connection: server + login, then Test
  • Input / Failed / Passed folders (default: admin's Documents; grant access to others)
  • Enable Update If Record Already Exists = overwrite
  • Stop After Upload Finished off = loader keeps watching the queue
  • Enable Drop = drag-and-drop files

7. Run it

  • Files in Input Folder show in Files to Process → Start
  • Active Transactions: Processing, Updated Records, Errors
  • Force Update: skip Insert, go straight to Sync (update only, no new records)

8. Logs

  • Logs link (top right): all WS transactions since last delete
  • Search highlights after 4 characters; green = match, gray = none
  • Find Next wraps to top; Info shows the call's XPath
  • Delete Log Files clears with no confirmation

Flow

Screen → Template→ UU prompt→ Fill .xlsx→ Input Folder→ Start→ Passed / Failed

Consultant tips

  1. Load 5 rows in TEST first
  2. Set Maximum Errors low
  3. Use Force Update for mass edits

Key points

  • Excel → web services
  • UU + last 4 chars
  • Failed file → Failed folder
