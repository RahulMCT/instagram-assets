📁 HxGN EAM Case Management CHEAT SHEET
Record events that are not work orders (accidents, spills, emissions, shift notes, line stops) and drive them to closure with tasks, follow-up WOs and root cause analysis. (HxGN EAM 12.1.1 brief)

1. Why a Case?

  • Event ≠ repair job, or WO need not clear yet
  • Many steps: OSHA, lawyers, inspections
  • Years later: proof corrective action was taken
  • Create manually, from Call Center or from Work Order

2. Status (CXST)

StatusEffect
RequestedFrom Call Center/WO: protected until Open
OpenEdit data, complete tasks
Closed / CanceledNo field updates
No return to Requested. Changes logged on Event Log.

3. Type (CXTP) + template

  • * = generic case, RCA = root cause analysis
  • Root Cause Analysis screen = clone of Case Mgmt
  • Service Code = template: Type, Class, Priority, Regulatory, est. costs + Case Tasks

4. Tasks tab

  • Sequence + Step (sub-sequence)
  • Responsible / Assigned To Role (JOBR)
  • Last task of a Sequence done = next Ready to Start
  • Firm Dates stop auto-moving
  • Task Plan for Checklist

5. Deep Dive + CASECASC

  • Tick Deep Dive + save: adds tasks from the org's Deep Dive Service Code
  • Untick + save removes them
  • CASECASC cascades scheduled task dates; Sched. End Date then protected

6. Follow-up WO

  • Needs Equipment on the case (or task)
  • Standard WO, WO Type/Class/Priority, Task Plan, Trade
  • No WO Status = Released
  • Create Follow-up WO + Refresh Cost Data
Equipment on case and WO is not kept in sync.

7. RCA tools

  • 5 Why fields + Problem / Solution
  • Root Causes tab: Contribution %, category, Keep Synchronized
  • Update Work Order writes closing codes, even to a closed WO
  • Fishbone tab: Why 1 = primary, Why 2 = secondary

8. Links + audit

  • Parent case, WO, Permit to Work, Shift, Project, Campaign
  • Related Cases tab, Document List
  • Event Log (ELTP), eSignatures, eRecords
  • Alerts: Case Task Completed / Ready To Start / Overdue Start

9a. Improvement loop

Equipment fails→WO fixes it→RCA case→Failure Modes→RCM tab

9b. Consultant tips

  1. Build Service Codes with Case Tasks first
  2. Use Notify flags + Alert Management
  3. Set Firm Dates on fixed legal deadlines
  4. Department security applies

9c. Key points

  • Case ≠ WO
  • Service Code = template
  • RCA feeds RCM
