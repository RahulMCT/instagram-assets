Workspaces & Workspace Moves Cheat sheet
Offices, people, assets and furniture in one record, and every relocation tracked from Open to Completed.

1. What it is

  • Track physical spaces: offices, meeting rooms, cubicles, work rooms
  • Link employees, equipment and furnishings to each space
  • Workspace Moves track relocations from one space to another

2. Workspace screen

FieldNote
Workspace No.Auto-generated
Workspace / Description / Org.Required
TypeCubicle, Office, Meeting Room, Other
StatusSystem statuses (temporary / full-time) + user statuses
Parent EquipmentLocation-type equipment, e.g. Room 124

3. Workspace tabs

  • Employees: many occupants → Employee field blank, Multiple Employees ticked
  • Equipment: read-only grid (laptop, printer, desk)
  • Furnishings: the Parts Associated tab relabelled (chair, shelves, lamp)

4. Who can occupy

  • Set up on the Employee screen, even contractors, students, volunteers
  • Tick Workspace Occupant; untick Tradesperson for non-employees
  • At least one of the two must be ticked
  • Occupant-only record: Trade = *

5. Where it shows up

  • Equipment screens: Current Workspace lookup
  • Work Orders + Call Center: Workspace lookup (cleared if Multiple Equipment)
  • Key Management > Locks: protected Workspace field
  • Read-only Workspaces tabs on Equipment and Employee

6. Workspace Moves

  • Required: Description, Org., From Workspace, To Workspace, Status
  • Optional drill-down: Campus → Building → Floor → Room/Unit
  • Drill-down needs OBJ classes with a Property Definition
Entity = OBJ Class = Campus Class Property Definition = Campus

7. Associations tab

  • On save, copies employees, furnishings, equipment of the From Workspace
  • Tick Include in Move on what moves
  • Org. option WSSELECT: YES = ticked by default, NO = unticked
  • Status not Open → tab protected

8. Move statuses

SystemBehaviour
O OpenEditable
A ApprovedAll fields protected except Status
C CompletedSelected items move; old links deleted; tab protected
CA CancelledProtected except Status

9. Link to a work order

  • Work Order-Activity lookup: status R, type JOB, not a Multiple Equipment child
  • DEPTSEC ON → only departments you can edit
  • WO > Workspace Moves tab shares the same table
  • Import Workspace Moves: open moves with no WO yet

10. Report

  • Workspace Moves and Associations List: what moves where
  • Covers employees, equipment, furnishings
  • Filters: Organization, Workspace Move, Status, From / To Workspace

Flow

Workspace→ Occupants + assets→ Move (Open)→ Include in Move→ Completed

Consultant tips

  1. Build Campus/Building/Floor classes first
  2. Decide WSSELECT before go-live
  3. Edit associations before you complete

Key points

  • Furnishings = parts, not assets
  • Completed = the actual move
  • Many user statuses per system status
