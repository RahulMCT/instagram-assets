Enterprise Search Cheat sheet
Search data across all screens: Interest Centers, Repositories and columns, generated and crawled through Infor IES.

1. What it is

  • Query data in the system across all screens from one search field
  • Screens-tabs + fields to include are set up on Enterprise Search Setup
  • Then generated via the Generate screen; results show as a tree
  • For system admins, developers + analysts

2. Interest Centers

  • Administration menu → Enterprise Search Setup
  • Record view: Interest Center Code / Description + Category
  • Top of the tree; groups repositories + fields
  • WORK: Work Orders, PM Schedules, trades · PURCHASE: POs, Requisitions, Blanket Orders
  • Category = not a validated lookup

3. Repositories tab

FieldExample / rule
Table NameDB table, e.g. R5EVENTS
RepositoryName of the repository
User FunctionScreen, e.g. WSJOBS; must match table
Tab NameTabs of that screen, e.g. Activities
ThumbnailHyperlinked image; http:// // \\ https://

4. Auto-filled (protected)

  • From Table Name: Date Created Column, Date Updated Column, Org. Column, Table Prefix
  • Popup checkbox ticked by the system if the user function is a popup
  • WORK can hold WO Activities, WO Parts, Service Requests, Work Orders, Employees…

5. Repository Columns

  • Pick repository → table + all its fields load
  • Editable only: Display Order, Alias, Facet
  • Code + Description default to 1 and 2 (top of result)
  • Alias = friendly name · Facet = groups fields (not validated)
  • Delete fields you don't want searched

6. Generate definitions

  • List-only grid of all interest centers + repositories
  • Select records → Actions → Download
output : definitions.zip upload : Infor IES (Definitions tab)

7. Infor IES upload

https://<ies_install_server>.infor.com:21000/ies/admin
  • Deployments → Upload deployment.zip (plugin source, don't modify)
  • Definitions → Upload a Definition → definitions.zip
  • IES 11.0.3 is not multi-tenant: prefix/suffix Interest Center + Repository with tenant id

8. Install app + crawl

  • Applications → Install Application; defaults + default memory heap
  • Select 1.0.0 eam deployment → Infor EAM details → Install
  • Application Details → Admin → Other Tasks → Load Resources
  • Immediately Crawl Repositories → check View Crawls
  • Test a Search; /grid/ui/ → Topology: red Log numbers = errors

9. Using the search

  • Type in field → search icon / Enter opens the popup
  • Results grouped by Interest Center (collapsible headers)
  • Hyperlinks open the record view; tabs not hyperlinked
  • Popup can move / minimise (bottom left); closing clears results
  • Empty field → popup with no records

10. ESEARCH & limits

  • ESEARCH install parameter null → icon won't open popup
  • Pressing Enter then prompts for an ESEARCH value
  • Field hidden on: caller login, generic web part, expired password, install parameter setup

Flow

Interest Center→ Repositories→ Columns→ Generate zip→ IES + crawl→ Search

Consultant tips

  1. Match Table Name to User Function
  2. Use Alias for cryptic column names
  3. Check View Crawls + Topology logs

Key points

  • Output = definitions.zip
  • Code/Description = 1, 2
  • Needs ESEARCH set
