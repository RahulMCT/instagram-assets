Investment Planning Cheat sheet
Budget + refurbish/replace options + capital requests in, an optimized multi-year plan out.

1. What it is

  • Takes budget for future periods + investment options (equipment) + capital planning requests
  • Returns an optimized investment plan per period
  • Engine: Asset Investment Planning (AIP) in Optimized Scheduler
  • Cloud only, not on premise

2. One-time setup

  • Register Optimized Scheduler Server URL + API key (MPConfiguration.xml OPSConfig)
  • Install param OPTMSCHL = YES (fixed once set)
  • Tenant pre-registered with Optimized Scheduler
  • Job Setup: activate INVPLREQ job
  • OTIMEOUT plays no role

3. Investment Options

  • Equipment Class Definitions > Investment Options tab (was Cost Types)
  • Type from System Codes RCTP: refurbishment / replacement
  • Estimated Costs (blank = free), At Age (years)
  • Maximum Recurrence 2 → overhaul at 10 and 20 yrs
  • Invest Early (years), Adjust Interval, Weight

4. Plan priorities

  • Equipment: OBCR criticality Weight and/or Risk Priority Number
  • Both selected → Weight × RPN
  • CPR Priority Basis: IRR / NPV / ROI / Priority (CPPR Weight)
  • Priority Override always wins
Plan Priority = Weight × -1 + Max Weight + 1

5. Investment Planning header

  • Status INST: Open / Closed (frozen)
  • Start Date in future; 1–99 Planning Periods (1 period = 1 year)
  • Yearly Inflation % compounds: $100 → $102 → $104.04
  • Allow Early Investments, Allow Budget Rollover (early first)

6. Budget Details

Funding TypeMeaning
Unlimited BudgetCost of doing everything
Yearly Increase+ fixed amount / yr
Yearly % Increase+ fixed % / yr (compound)
  • Negative increase allowed; budget never < 0

7. Equipment tab

  • Age = (Date Created − Commission Date) / 365, or usage-based
  • Age Correction from Correction Condition Score (10-yr car in 6-yr condition → −4)
  • Age Increment per Period: 50000 ÷ 25000 mi = 2
  • Valid Investment Option: same Class + Category + Org, At Age filled

8. Capital Planning Request tab

  • Refresh Investment Period: (Requested) Appropriation Date − Start Date ÷ 365, min 1
  • Investment Period Override, Invest Early (years)
  • Option cost = est. labor + material; weight 1; age 1

9. Request process

Start Planning → Planning Status Requested INVPLREQ job → Executing (Planning Run Id) Optimized Sched.→ Completed (Planning Run Date)
  • Out of Service plans silently ignored
  • Create New Revision to test another budget

10. Planning Results tab

  • Budget: Total Period Cost vs Period Budget
  • Planned Investment Option: period, Option Cost, early / on time / late
  • Unplanned: no budget, Option Age shown
  • Excluded Equipment: no valid option (e.g. no Class)

Flow

Options + weights→ Plan + budget→ Add equip. / CPRs→ Start Planning→ INVPLREQ→ Results

Consultant tips

  1. Class every asset first
  2. Don't mix equip. + CPRs
  3. Revision per budget

Key points

  • Cloud only
  • 1 period = 1 year
  • Override beats calc
