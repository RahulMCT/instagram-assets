📉 HxGN EAM Equipment Depreciation CHEAT SHEET
Value an asset over its useful life, event by event. (Infor EAM Equipment Depreciation brief, 11.5)

1. Where it lives

  • Assets screen → Depreciation tab
  • Fields: Type, From Date, Category, Method, Change Value / Life / Est. Lifetime Output
  • Relative Start + UOM for Equipment Configuration
  • Tab supports UDFs

2. Depreciation Types

  • Entity DETP, default *
  • GAAP, GASB, IFRS + user-defined
  • Informational only: track operational vs accounting standards side by side

3. Straight Line

(Starting − Residual) / Useful Life ($5000 − $200) / 5 = $960 per year
  • Simplest, most common

4. Sum of Years Digits

5 yrs → 5+4+3+2+1 = 15 Yr1 = $4800 × 5/15 ≈ $1600 Yr5 = $4800 × 1/15 ≈ $320
  • Accelerated: more value lost early

5. Double Declining Balance

SL rate 20% → doubled 40% Yr1 $4800 × 40% = $1920 Yr2 $2880 × 40% = $1152 Yr3 $691.20 < $960 → switch to SL

6. Units of Output

Rate = (Starting − Residual) / Est. Lifetime Output Dep = Rate × Units produced
  • Idle asset = zero depreciation
  • Best for assets with varying usage

8. Rules to remember

  • Change Value = 0 → Residual Value opens for edit
  • Recalc runs from From Date, replaces same/projected dates
  • Change Method: Units of Output excluded once records exist; blocked after Early Disposal

9. Setup steps

Add Depreciation Type→From Date = Commission Date→Method→Starting / Life / Residual
  • View Depreciation Details: To Date, Book Value, Period to Date

10. Equipment Configuration

  • Plan future events on templates
  • Relative Start + UOM required
  • Commission 1/1/2015 + 5 Years → event in 2020

Flow

Commission→Periodic calc→Life / Value events→Suspend / Reactivate→Early Disposal

Consultant tips

  1. Pick Units of Output on day one if usage drives value
  2. Log PM upgrades as Increase Life / Value
  3. Use one Type per accounting standard

Key points

  • 4 methods, 11 categories
  • Events recalc from From Date
  • Early Disposal is final
