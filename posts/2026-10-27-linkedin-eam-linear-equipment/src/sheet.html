🛤️ HxGN EAM Linear Equipment CHEAT SHEET
Roads, rail, pipelines: assets with a length, where work happens "from mile 6 to 7", not on the whole asset. (Infor EAM 11.7 Linear Equipment brief)

1. What makes it linear

  • Assets, Positions, Systems can be linear
  • Equipment Length + UOM (m, km, ft, mi)
  • Linear Reference UOM: km road, features in metres
  • From Point shifts everything: a 10-mile road starting at marker 65 shows mile 1 as 66

2. Linear Equipment Type (LETP)

TypeExample
RTOW Right of WayInterstate 40
ROUT RouteEastbound lane, track 1
SEGM SegmentSmallest piece; a switch can be a point
Type and Direction (LDIR) go together. Leave both blank and you lose offsets + Trace.

3. Linear References tab (LRTP)

  • Linear Reference System: mileposts, markers
  • Point of Interest: one-off, e.g. welcome center
  • Related Equipment: bus stop, bridge, culvert
  • Related Part: ties, gravel, cable
  • Class (entity LREF) groups rows on the overview

4. Locating a feature

  • From / To Point, 0 to 6 decimals
  • From Reference (a milepost) + Offset / Offset % + Offset Direction
  • Point Reference: To = From
  • X/Y, Lat/Long, horizontal + vertical offsets
milepost 5290 ft + 25 ft North = 5315 ft

5. Smart data entry

  • Repeat Every Length: 5,000 ft asset, start 1,500, every 1,000 → 4 rows (1,500 / 2,500 / 3,500 / 4,500), one Set ID
  • Apply to Children / Apply to Route/ROW: define once
  • Split (2 parts) and Insert Inside (3 parts) expire the old row, history kept

6. Condition + Overview

  • Linear Condition tab: Condition, Risk Priority, Criticality scores/index, colors from Equipment Ranking
  • Linear Overview: graphical bar, needs Display on Overview and Class
  • Filter WOs, Inspections, Nonconformities, Checklists; Effective date = past view
  • Dataspy shows first 500 only

7. Segments, Routes, Branches

  • Segments tab only on a Route; Routes tab only on a Right of Way
  • Branch Point pairs (same Equipment or Branch Identifier) = crossover
  • SRSTSYNC I / D / ID keeps structure in sync
  • Linear Cost Weight (Systems): weight 2 vs 1 → 2/3 vs 1/3 of cost

8. Linear work orders

  • WO From/To Point within the asset; activities within the WO range
  • Reference Points against direction? EAM swaps From/To on save
  • Equipment, Checklist, Inspections tabs + Deferred Maintenance carry From/To
  • WOFUFPTP=NO: one follow-up WO per From/To combo

9. Trace Route + linear PMs

FeatureWhat it does
Trace Route popupPick a route + From/To, Add To List, cross over via branch points, Continue Trace / New Trace, Add all Routes of Right of Way, Add Related Equipment, Submit
MEC Work Orders flagTicked: Multi-Equipment Child WOs; else regular child WOs. Copy Activities optional
TRACELEVROUTE = one child WO per route · SEGMENT = one per segment touched (more WOs)
Breakdown Linear Work (PM Schedules)Add the asset with From/To on the Equipment tab, then split it into smaller sections; save generates Equipment tab rows

10a. Setup flow

Linear Direction Setup (pairs)→Classes OBJ + LREF→Right of Way / Route / Segment→Linear References→Linear WO / PM→Linear Overview

10b. Consultant tips

  1. Set Type + Direction on day one
  2. Predefine references on the Class
  3. Use Random Results for linear inspection aspects
  4. ALTPOINT=PLUS100 shows 123+45 stationing

10c. Key points

  • Work on any slice of the asset
  • History via Effective / Expired
  • Branch points drive tracing
