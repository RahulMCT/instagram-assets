🏷️ HxGN EAM Barcoding CHEAT SHEET
Design, print and reprint barcode / QR labels for parts, stock, bins and equipment, straight from EAM transactions, EAM Mobile or batch runs. (HxGN EAM 12.3 Barcoding brief)

1. What + install

  • Windows app to identify, label, collect, transfer and track parts
  • Setup: Apache (Tomcat) or IIS as Print Job Receiver, or Custom = Batch Printing only
  • Barcoding version must match EAM (v11.5 ↔ v11.5)
  • Add EAM app server as a trusted site

2. Users + licences

  • Administration › Security › Setup › Record View › tick HxGN EAM Barcoding
  • LDAP: same flag on Role Setup
  • Active users capped by CDKEY (EAM) / 7IBCDKEY (Mobile)
  • At least one Mobile Administrator runs the first data sync

3. App menus

MenuTabs / use
Print JobsJobs, Job History
TemplatesTemplates, Page Layout, Label Designer
Batch PrintingFilter, sort, preview, print
Server SettingsSettings, Printers, Logs

4. Template data sources

  • Equipment, Location, Meter Equipment
  • Stores, Parts, Stock, Bins, Suppliers, Employee
  • Issue/Return Parts, On-Dock Receipt, Storeroom Receipt
  • Templates can be Imported / Exported

5. Page Layout + Label Designer

  • Unit: English (inch) / Metric (cm)
  • Print Type: Single Sheet / Continuous
  • Custom format: margins, spacing, height/width, Across × Down
  • Per field: Display Barcode / Label / Value + Font Size
  • Drag in preview → Barcode Position X/Y

6. Symbologies

  • Code 128, Code 39, Code 39 Ext
  • UPC-A, UPC-E, QR Code
  • Barcode Height, Text Font, Number of Duplicates
A QR code still holds ONE string (e.g. only the Part Number). No extra data packed in.

7. Label Server URL (Stores)

IIS (path must be UPPERCASE):

http(s)://[server]:[port]/PRINTJOBRECEIVER/RECEIVER.ASPX

Apache/Tomcat:

http(s)://[server]:[port]/PrintJobReceiver/ReceiverServlet
Tomcat ships a self-signed cert: swap for a CA cert (server.xml › certificateKeystoreFile) and restart the service.

8. Server Settings

  • User ID, Password, Organization, Connection ID, Server Address, Proxy
  • Retrieval Interval (s), Retries on Errors
  • Keep Job History / Server Log (days)
  • Test Connection; must be set before printing
  • Logs tab: Purge All

9. Printing from EAM + Mobile

WhereLabels print on
EAM screensIssue/Return Parts · Non-PO Receipts (Parts tab) · PO Receipts (Active Lines tab) · Store-to-Store Receipts (Parts tab) · Held Items Transfer · Held Items to Stock · Stock to Held Items
EAM MobileIssue Part, Return Part, PO Receive
Template fieldsOn Stores record + Parts › Stores tab: Receipt, Non-PO Receipt, Issue, Store-to-Store, Held Items (Receipt / on PO / on Non-PO / Transfer / to Stock), Stock to Held, Core Return (Parts › Stores tab only)

10a. Print flow

EAM / Mobile transaction→Stores label template→Label Server URL→Print Job Receiver→Printer→Job History (reprint)

10b. Consultant tips

  1. Check URL case for IIS first
  2. Test Connection before go-live
  3. Reprint can change Template + Printer
  4. Batch filters accept relative dates: >="-7"

10c. Key points

  • Template = data source + layout
  • Stores holds the template
  • Versions must match
