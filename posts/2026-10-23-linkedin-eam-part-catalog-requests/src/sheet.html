🗂️ HxGN EAM Part Catalog Requests CHEAT SHEET
A request form for new or changed parts, pricing, suppliers, manufacturers and store data, approved before anything touches the Part master. (HxGN EAM Part Catalog Requests brief, 12.3)

1. Why it exists

  • Clean part catalog = accurate financial + inventory reporting
  • Requestor fills the form, a parts specialist checks for duplicates
  • Nothing is inserted / updated until approved

2. Two system types (CQTP)

TypeRequested Part field
New Part RequestText field, follows AUTOPNUM
Update Existing PartLookup to pick the part

3. Not supported (Update)

  • Track By Asset
  • Track By Kit
  • Repairable Spare
  • Calibration Standard
  • Track by Condition

4. Change Part Number

  • Update type: tick Change Part Number + enter New Part Number
  • Pick an existing part = merge duplicates
  • Or type a number that doesn't exist yet
Runs only on approval, like the Part right-click option.

5. Preserve Part Data

  • Update only suppliers / manufacturers / store
  • Part record view stays untouched
  • Tip: cloned screen with it checked + protected = a "Min/Max Request"

6. Pricing rules

  • Updates only if Average / Last / Standard price entered
  • Price change creates a CORR transaction
  • Protect price fields to block updates
PRICELEVBehaviour
PPrice Type required, defaults to PRICETYP; not for common-org parts
SPricing protected until Include Store Request

7. Supplier / Manufacturer

  • Creates the record on approval if it doesn't exist
  • Existing record: fields default in, edits update it
Old supplier catalog record is NOT kept as an alternate.

8. Store + Approval

  • Include Store Request: create / update the part's store record (reorder setup)
  • Approval Workflow entity: Default Approver, Approval List
  • On approval: UDFs, comments, documents copy to the part
  • Approved = all fields protected, even status

9a. Request flow

Requestor fills form→Parts specialist review→Approval Workflow→Part / Supplier / Store updated

9b. Consultant tips

  1. Clone the screen per Type / Class (Screen Setup)
  2. Use Change Part Number to merge duplicates
  3. Protect price fields if finance owns pricing
  4. Finance approval for keep-stock requests

9c. Key points

  • 2 types: New / Update
  • Approve = write to EAM
  • Price change = CORR
