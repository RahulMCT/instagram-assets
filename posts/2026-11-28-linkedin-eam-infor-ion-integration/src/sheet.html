Integrating with Infor ION Cheat sheet
BODs in and out through Databridge: setup, subscriptions, MRO and planning flows.

1. What it is

  • Built-in link from EAM to other Infor apps on Infor ION
  • Messages are BODs with Process / Sync verbs
  • Pipe = Infor OnRamp inbox/outbox, reached through Databridge partners
  • 3 usages: Infor Dashboard, ERP MRO materials & services, ERP Advanced Maintenance Planning

2. Before you start

  • EAM servers up; at least one with Databridge enabled
  • ION installed: Tenant + Logical ID for this EAM instance
  • EAM tenant must match the ION tenant
  • ION Connection Point import file: ask support for SCR-45668
  • Inbox/outbox lives in a DB schema: EAM's own or a dedicated one (multi-tenant → one schema for all tenants; dedicated needs the table script, SCR-37785)

3. Enable outbound events

  • Databridge Setup → Options page, or the equivalent install parameters

4. INFOR-ONRAMP partner

  • Databridge Partner: partner * (My Enterprise) → Active
  • Dataspy All Partners → INFOR-ONRAMP → Active
  • Partner ID = last segment of the Logical ID
lid://infor.eam.instance01 → Partner ID: instance01 jdbc:oracle:thin:@host:1521:SERVICE jdbc:sqlserver://host:1433;DatabaseName=DB
  • Inbox/outbox in EAM schema → leave Response Details Address / Login ID / Password blank; else enter the JDBC string + DB login

6. MRO flow with ERP

  • Parts & services (= Trades) mostly from ERP via SyncItemMaster; suppliers & cost codes kept outside EAM
  • Approved requisition → ProcessRequisition → ERP PO → SyncPurchaseOrder
  • Receipt either side: Process/SyncReceiveDelivery
  • Issue to WO → ProcessShipment; return to store → ProcessReceiveDelivery (no PO)
  • Physical count → ProcessInventoryAdjustment
  • Entity-level master data → Multi-Org on CSTC, PART, TRAD, COMP

7. Advanced Maintenance Planning

  • Released WO needing downtime → approved Production Request → ProcessProductionOrder
  • ERP scheduler sets order to Firm → SyncProductionOrder
  • EAM updates the WO schedule from that message
  • WO closed → ProcessProductionOrder asks for Completed
  • Either side can cancel

8. Dashboard feed

  • ProcessCodeDefinition: accounting entities, cost centers, WO types, departments, MRO classes, PM schedules, DIMENSIONS
  • Asset created / updated → ProcessAssetMaster
  • WO Released or Completed → SyncMaintenanceOrder
  • Meter reading / green calculation → SyncAssetMeterReading

9. Org & store mapping

  • Organization form → Accounting Entity
  • Enterprise Locations tab: one row per BOD Group Asset / Materials / Purchasing / Work
  • Common * org usually not mapped (tenant-level master data lands there)
  • Store form → Enterprise Location = ION warehouse Location Code

Flow

EAM event→ Databridge→ INFOR-ONRAMP→ Outbox→ ION→ ERP / Dashboard

Consultant tips

  1. Switch outbound on only when the interface is ready
  2. Set @UPDINV to N during initial inventory loads
  3. Simplified MRO = legacy only, not for new projects

Key points

  • Partner ID = Logical ID tail
  • Tenants must match
  • Map orgs + stores
