🛡️ HxGN EAM RCM: Risk & Reliability CHEAT SHEET
Reliability Centered Maintenance: Risk Matrix → Risk Assessment / Analysis / FMECA → Mitigation with PMs. (Infor EAM RCM brief, 11.7 docs)

1. Setup: project + matrix

  • RCM Project = System Codes entity STPR (max 8 chars, system code *)
  • Default project's matrix is used unless the Organization picks an RCM Project
  • One Risk Matrix per RCM Project

2. Risk Matrix Setup types

TypeExample
Consequence CategorySafety, Environment, Profitability
Probability<1 yr, 1–5 yrs, >20 yrs
Risk LevelDesirable … Catastrophic
Consequences + Severity on the Consequences tab; cost per Organization on Consequence Cost tab.

3. The RPN formula

RPN = Probability Rating
× Consequence Severity
  • Most desirable = 1, higher = worse
  • Header shows the highest RPN from the RCM tab
  • Risk Level = matrix level matching the RPN via Rating/Threshold

4. Pick the RCM Level

LevelDefinesWhere
Risk AssessmentFunctions → Functional Failures → ConsequencesHigh in hierarchy (lines, locations)
Risk Analysis+ Failure ModesLower-level equipment
FMECAFailure Modes instead of Functional FailuresAny

5. Build the RCM tab tree

Functions→Functional Failures→Consequences→Failure Modes→FF for Failure Modes
  • Failure Mode holds WO defaults: closing codes, Standard WO, downtime, TACA / HUFA / WOMS / HUOV / MOFD
  • Picking it on a WO defaults these

6. Black Swan ⚫🦢

  • Low probability, very high cost
  • Tick it only on the lowest probability and worst consequence
  • Header flags Black Swan + Black Swan Cost when both match
Usually doesn't drive the RPN, so it's easy to overlook. That's why it's flagged.

7. Failure Mitigation tab

  • Only for Risk Analysis / FMECA
  • Mitigated Probability → new RPN preview
  • Measures: PM Schedule, Maintenance Pattern, PM Plan, Project, Case, Aspect
  • One-time + Recurring Mitigation Cost
  • Mitigation Applied = active; lowest active rating wins

8. Activate Mitigation

  • Adds equipment to the PM Schedule + syncs intervals
  • Adds to Maintenance Pattern, activates 1st sequence
  • Adds to PM Plan
PM State: Not attached | Multiple attached
| Not active | Different frequency
| Different meter UOM | Mitigated

9. RCM Templates

  • Status RTST: Unfinished → Request Approval → Approved → Superseded
  • Revision control; RCM data editable only when Unfinished
  • Equipment Classes tab: */* = generic
  • Import: Probabilities / Consequences / Mitigation (always imported not applied)

11a. RCM loop

Assess line→Analyse high-risk child→Mitigate top RPN→Activate PM→Report

11b. Consultant tips

  1. Matrix edits don't trickle down: re-check RCM tabs
  2. Analysis → Assessment needs Failure Modes deleted
  3. Start mitigation at the highest RPN

11c. Key points

  • 3 RCM Levels
  • RPN = P × S
  • 4 RCM reports
