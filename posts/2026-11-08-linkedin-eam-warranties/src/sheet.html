🛡️ HxGN EAM Warranties & Claims CHEAT SHEET
Stop paying for repairs the OEM already owes you. (Infor EAM Warranties brief)

1. Warranty record

  • Warranty Type: Equipment (default) or Part
  • Manufacturer, Supplier, Control Number
  • Agreement Start / End, On-site Repair, Loaner Provided
  • Renewal Alert Email

2. Start Date Basis

  • Equipment: Commission Date (default), Original / Latest Receipt, Original / Latest Install, Agreement Start
  • Part: Agreement Start or blank
  • Default Duration + Renewal Threshold (days)

3. Cost coefficients

Labor %, Hired Labor %, Services % Stock Items %, Direct Purchases % Tools % → all default 100
  • Max Labor / Stock Amount per claim

4. Fixed overrides

EnterClears + protects
Fixed Labor RateLabor, Hired Labor, Services %
Fixed Labor Amountthose 3 % + Fixed Labor Rate
Fixed Stock AmountStock Items %, Direct Purchases %

5. Equipment coverage

  • Calendar (days, default) or Usage (UOM)
  • Usage UOM must be a logical meter on the equipment
  • Only Asset, Position, System. No Locations
  • Threshold flags upcoming expiry

6. Parts & Components

  • Parts tab: Warranty Days after issue
  • Reimbursement: R Replacement / C Cash (default)
  • Components (ex-VMRS codes): System → Assembly → Component level, own cost coverage

7. Warranty claim math

WO internal labor = $500 Warranty Labor % = 80 WO Labor on claim = $400 No warranty on claim → 100%
  • Only warrantable activities / jobs count

8. Creating claims

  • Warranty Claim screen, or Create Warranty Claim popup on WO, Activity or Job tab
  • One non-cancelled claim per WO + Activity + Job
  • RMA Required → RMA Number mandatory
  • Parts: Part Warranty Claim + Import Parts

9. Claim status rules

  • New claim starts Unfinished
  • Approved, Response Received, Completed, Cancelled → Activities tab protected
  • Settlement Details: Date Resolved, Total Settlement

10. Issue / Return Parts

  • Same part, same equipment + component location, inside warranty period → Warranty box ticked + warning
  • Logged in r5warclaimparts
  • Print Warranty Return Label(s): qty 1, not on Returns

Flow

Warranty→Coverage→Failure WO→Claim→Settlement

Consultant tips

  1. Flag warrantable activities before costs post
  2. Keep Exclude PM Work Order on to cut PM noise
  3. Set Renewal Alert Email on day one

Key points

  • % coefficients default 100
  • Fixed values override %
  • Usage UOM = logical meter
