🦺 HxGN EAM Safety & Permit to Work CHEAT SHEET
Hazards → precautions → LOTO → permits → PTW. (HxGN EAM Safety Management brief, 12.1)

1. Three components

  • Safety (hazard + precaution)
  • Lockout/Tagout (LOTO)
  • Permitting (permit → permit to work)
  • Built for OSHA / EU-OSHA style compliance

2. Hazards & Precautions

  • Define each Hazard (HZST) and Precaution (PCST) separately
  • Precaution has Timing (before/during/after), Responsibility, review date
  • Both under revision control: edit only when Unfinished
  • Approve → old revision superseded

3. Safety tabs

  • On Assets, Locations, Categories, PM Schedules, Std WOs, Parts, WOs, PTWs
  • Apply to Children = inherit down the hierarchy
  • Review via e-Signature sets next review date (SAFERFRQ)
  • Edit a record → tab goes un-reviewed

4. Safety Matrix

Equipment / Class / Category+Activity→Hazard
  • Activity = PM Schedule, Std WO, Task/Job Plan or Tool
  • e.g. welding + tank with flammable liquid

5. WO auto-population

  • New WO (manual, PM or pattern) copies safety records from equipment, location, parents, parts, Std WO/PM, Safety Matrix
  • Nothing is auto-removed: delete manually
  • WO tab stores hazard + precaution revision

6. LOTO setup

Isolation Method (Task)+Isolation Point→LOTO tab
  • Point has Energy Source (ESRC) + Residual Energy (RSDE)
  • LOTO steps flagged Isolation Step or de-isolation; Isolation Type picks the procedure

7. Permits & PTW

  • Permit = template on the WO; Auto Create PTW needs PTW Type + Risk
  • LOTO Required copies LOTO from equipment
  • Mandatory flag; PTWLIMIT = one open PTW per WO
PTWAUTO=YES → PTW auto-created PERMCLEA = NO | DEACT | DEL

8. PTW lifecycle

Unfinished→Request Approval→Approved→Active→Expired→Closed
  • Also Cancelled / Suspended
  • Duration + Extend (e-Sig) = Valid Until

9. Isolated & Lockout Box

  • Isolated button (e-Sig) sets flag on PTW + isolation points
  • Lockout Box → In Use + Current PTW
  • De-Isolated reverses it

10. Conflicts tab

You pickSister PTW (SYNC)
Finish AfterFinish Before
Finish BeforeFinish After
No ConflictNo Conflict
  • PTWCONFL = SYNC or MANUAL

Flow

Hazard→Precaution→WO safety tab→PTW→Isolated

Consultant tips

  1. Set up Isolation Methods before LOTO records
  2. Review tabs with e-Signature after any change
  3. Check SAFESYNC / SAFERREV before approving revisions

Key points

  • Revision control everywhere
  • Permit = template, PTW = live
  • Lockout Box tracks In Use
