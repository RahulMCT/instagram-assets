🔬 HxGN EAM Calibrations CHEAT SHEET
Compare a device reading under a known standard load across test points — then prove it on Work Orders. (HxGN EAM Calibrations 12.3 brief)

1. What & why

  • Calibration = test unknown reading vs a known standard
  • Need points across the full operating range (test points)
  • Regulated industries: pharma, oil/gas, food, automotive
  • Base EAM product — devices, standards, PM, WO results

2. Core objects

  • Devices = Equipment (asset / position / system)
  • Standards = Parts with Calibration Standard checkbox (or asset Parts)
  • Results documented on Work Orders
  • Frequency via PM Schedules / Maintenance Patterns

3. Equipment setup

  • Calibration tab: tolerances, precision, increment, ranges, Default Set, SOP
  • Test Points tab: Set + Sequence = PK (Sequence 0–9999)
  • Set groups weekly / monthly / annual point lists
  • Some fields default from device; blank TP uses device-level on WO

4. Categories & generate

  • Categories = attribute templates (Calibration + Test Points tabs)
  • New Equipment with Category → copies cal data once at create
  • Update Equipment / Update Equipment Configurations cascade later changes
  • Equipment Configurations + Generate Equipment = batch devices

5. Standards Used

  • Tick Calibration Standard on the Part
  • Associate on Equipment → Parts Associated
  • On WO Calibration tab: Standards Used popup
  • Flagged parts copy to the WO; technician can adjust / pick asset

6. Process Loops

  • Loop = group calibrated together, not device-by-device
  • Loop Equipment: Loop checkbox + owns the test points
  • Input instrument: Type = Standard applied to
  • Output instrument: Type = Reading taken from
  • WO header = loop; each TP equipment = reading-taken-from

7. WO Type = Calibration

  • Copies device header + test points to WO Calibration tab
  • Also via Standard WO, PM, Patterns, Alerts, Flex rules
  • PM: set Test Point Set + Calibrations WO Type (else no copy)
  • As Found → optional Copy to As Left after adjust

8. Precision (v12.0+)

ParamMeaning
CALTZERO=Aauto trailing zeros to match precision
CALTZERO=Bonly user-entered trailing zeros kept
CALTZERO=Cexact decimals required (+ CALRPREC)
CALPRECON/OFF precision on Output (etc.)

9. Status & reports

  • Calibration Status (calculated): Incomplete · Pass · Pass – Recal Exists · Pass – Fail Exists · Fail
  • Test point Status: Pass / Fail / Recal (Alert Tolerance band → Recal)
  • Reports: Due · Equipment · History · Record · Reverse Traceability · Analysis

10a. Flow

Equip + TPs→Standards→PM / Type=Cal→WO Calibration→Status + Reports

10b. Consultant tips

  1. Decide CALTZERO before go-live data entry
  2. Use Sets for multi-frequency PM
  3. Always set Calibrations WO Type on PM
  4. Reverse Traceability for standard recalls

10c. Key points

  • Set+Seq = PK
  • Type=Calibration copies
  • Status is calculated
