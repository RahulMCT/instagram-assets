🔧 HxGN EAM Mechanic's Workbench CHEAT SHEET
The technician's To Do list: start, stop and complete work, and labor books itself. (Infor EAM Mechanic's Workbench brief)

1. What it is

  • Central screen for mechanics: assigned WO activities, task details, equipment
  • Start / Stop / Complete work from one place
  • Stop Job creates the book labor record

2. What fills the list

  • Scheduled labor records of the employee
  • Daily Scheduling: WO Daily Scheduling, Schedule Labor tab, WO Scheduling
  • Shift Scheduling: only the Shift Scheduling tab

3. Shift auto-pick

a) earliest shift starting in next 8 hours b) else latest shift ended in last 8 hours (ongoing ok) c) else Shift stays blank
  • Blank Shift → Daily records for yesterday, today, tomorrow

4. Header fields

  • Employee: from logged-on user (else enter it)
  • Shift Session / Start / Duration: from Shift
  • Type of Hours: set it BEFORE Start Job, used on the booking
  • Password: optional, only checked if entered

5. Work Details grid

FieldMeaning
StartedActivity/job running; default Dataspy sorts it to top
Scheduled TradeFrom scheduled labor
Planned TradeFrom WO activity
Main ResourceScheduled trade = planned trade

6. Due Percentage

PM every 100 days, last done 90 days ago → 90% 12 days later → 102%
  • Calendar + meter PM: highest % shown

7. Start / Stop / Complete

  • Start Job: checks pass → temp start record, Started ticked, Timer runs
  • Start another job → current one auto-stopped first
  • Stop Job: no selection needed; failed check → no labor record, book manually
  • Complete Job: Completed ticked, 100%, Hours Remaining 0

8. Timer & links

  • Timer = now minus start time; keeps running if you leave the screen
  • Timer at zero = nothing started
  • Actions → View Comments / View Documents (Task Plan, Job Plan, PM, Pattern, activity)
