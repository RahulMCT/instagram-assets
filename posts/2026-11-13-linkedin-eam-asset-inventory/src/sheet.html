Asset Inventory Cheat sheet
Physical asset audits: count, reconcile, resolve and approve, on desktop or mobile.

1. What it is

  • Periodic asset audits: reconcile the location EAM thinks an asset is in with where it really is
  • Set counting criteria → EAM generates the asset list
  • Count manually or on the mobile / tablet app
  • Reconcile, review and approve the count

2. Session parameters

  • Session ID: system generated, retrieve it later to continue
  • Required: Physical Location Type, Physical Location Parent, Assigned To, Description
  • Narrow by Asset Org, Department, Asset Class, Asset Status, Inventory Verification Date
  • Standard WO: template for Move WOs

3. Physical Location Type

TypeAsset is listed when
LocationLocation populated, Dependent boxes off
PositionPosition populated
SystemParent is its Parent System
In StoreStore populated (Parent Store required)
  • Any level below the selected parent

4. Mobile & iPad options

  • Blind Inventory: Results tab data is NOT synced to mobile, so counters don't see the expected answer
  • Allow Move WO(s): iPad user can create Move WOs
  • Allow Physical Location Updates: iPad user can change the asset structure
  • Options are per session

5. Verification Date filter

Inventory Verification Date = today (default) → excludes assets verified AFTER this date Create/Update Session → params locked (except Session ID + Standard WO)
  • Clear Session ID to start a new session

6. Inventory Results Dataspies

DataspyShows
Needs ResolutionDefault: Needs Disposition ticked
ResolvedResolution filled in
All recordsEvery asset in the session
  • Needs Disposition recalculated on every grid save: Observed ≠ System location, or System location blank, with no resolution

7. Grid actions

  • Update System with Observed: writes location + verification date to the asset
  • Copy System to Observed: grid only, no asset update
  • Mark as Not Found: only when Observed is blank
  • Create Move WO(s): needs a Standard WO
  • Create New Asset / Add Asset to List (status Installed)

8. Approve: AINVAPP

Org option AINVAPP (Observed location blank) FOUND → "Asset Found" (default) NOTFOUND → "Asset Not Found" BLOCK → approval blocked if unresolved
  • Observed = System → "Asset Found"
  • Approve or Cancel protects all fields

9. Mobile counting

10. What syncs

  • Only unfinished sessions assigned to the mobile user
  • Approved / Cancelled sessions don't sync
  • Updates in the base product sync back to the device
  • Create Move WO is protected without a Standard WO

Flow

Parameters→ Create Session→ Count→ Resolve→ Approve

Consultant tips

  1. Set AINVAPP before the first audit
  2. Use Blind Inventory for honest counts
  3. Always enter a Standard WO

Key points

  • Copy ≠ Update (grid vs asset)
  • Default AINVAPP = FOUND
  • Add to List needs Installed
