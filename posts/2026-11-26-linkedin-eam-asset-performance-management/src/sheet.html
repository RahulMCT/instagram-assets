Asset Performance Management Cheat sheet
Condition, capacity, MTBF and MTTR, weighted into one performance score per asset.

1. What APM is

  • Framework to use physical assets to reach business goals, maximize profit, reduce risk
  • Key elements: defined level of service, demand & capacity planning, lifecycle approach, risk control, long-term financial plan

2. The 6 steps in EAM

  • 1 Develop asset registry (Assets, Positions, Systems)
  • 2 Asset residual life (Decay Curves, Equipment Ranking)
  • 3 Business risk (RCM, risk/criticality indexes)
  • 4 Target level of service (ISO 55001 Policies / Strategies / Objectives)
  • 5 Assess asset performance
  • 6 Build the APM plan: lifecycle & replacement costs, maintenance spend, capital investment, funding strategy (needs some configuration out of the box)

3. Performance = 4 pillars

PillarMeasured by
ConditionCalculated condition score
CapacityDriving parameter vs needed throughput
ReliabilityMTBF (mean time between failure)
MaintainabilityMTTR (mean time to repair)
  • + up to 6 extra variables = 10 weighted ratings

4. Performance Formulas screen

  • Status entity PFST: Unfinished (U) editable → Request Approval (RA) → Approved (A) usable
  • Weights 0–1 per rating; 0/blank = excluded
  • Capacity Code from System Codes entity CACO
  • Date Approved auto-set; decides which equipment rolls up

5. MTBF / MTTR rules

  • Failures = technically completed BR (breakdown) WOs, past year; Include Children optional
  • MTBF (Days) = 365 / Failures
  • Max Allowable Failures/Year 10 → 5 failures = rating 50, 0 = 100
  • Usage Based → MUBF; 150 mi/day: 365*150/10 = 5475 mi/failure
  • Repair time: Downtime Hours if present, else Daily Maximum Booked Hours or WO Closed / Reported

6. Rating math (all 0–100)

Condition = score rescaled to 0–100 Capacity = Available / Desired * 100 MTBF = 100 - Failures*100/MaxFail MTTR = 100 - RepairHrs*100/MaxHrs Performance = Σ (Rating × Weight)
  • Capacity = 100 if blank, Desired 0, or > 100

7. Custom variables 1–6

  • Query from Queries screen, must return a number (Equipment Ranking query with :OBJECT / :OBJECTORG)
  • Best / Worst Acceptable Result: Best 50, Worst 25 → ≥50 = 100, ≤25 = 0
  • Swap them when lower is better

8. Class Definitions & roll-up

  • Formula assigned on Class level only; categories share it
  • Lookup: class + org → org + */* → * + */*
  • Auto Create Class / Category Level sets Auto Created flag
  • Capacities tab: Capacity, Desired Capacity, Date Effective / Expired; Total Desired Capacity on class
  • Roll-up excludes Withdrawn & Awaiting Purchase (A, D)

Flow

Asset registry→ Formula (Approved)→ Class Definition→ Equipment score→ Category / Class

Consultant tips

  1. Put UOM in CACO descriptions
  2. Enter capacity on class, exceptions on equipment
  3. Recalculate after re-approval

Key points

  • 10 variables, weights 0–1
  • Only Approved formulas run
  • Failures = BR WOs
