Operator Checklist Cheat sheet
Equipment checks by the operator without a work order: fill, sign, review, complete.

1. What it is

  • Fast equipment checklist entry by the operator, no work order needed
  • Select Equipment → Task Plan → Save / Checklist → fill items
  • Results go to supervisor review or straight to completion
  • Min. setup: a task plan with a checklist + equipment

2. Screen Setup tab

  • Header must be WSOPCL (Operator Checklist) or a clone
  • Equipment Class → allowed Task Plan(s); * class in * org for unclassed equipment
  • Default auto-fills the task plan; use only ONE (multiple = random pick)
  • Complete Status + Cancel Status (OPST)

3. OPST statuses

StatusEffect
UnfinishedOperator can still edit
ReviewGoes to Review Operator Checklist
CompleteFrozen, review bypassed (default)
CancelledFrozen via Move to Cancel

4. Task plans excluded

  • Joint plans (Perform By 2 Responsibility entered)
  • Isolation methods
  • Nonconformity checklists
  • Case management checklists
  • No setup → every task plan with an active checklist is listed

5. Buttons

  • Create Checklist = Save; reopens YOUR unfinished one from today (same equipment + task plan)
  • Move to Complete → setup Complete Status (Unfinished / Review / Complete)
  • Move to Cancel → Cancelled
  • Items behave like the WO Checklist tab

6. e-Signatures

  • Performed By / Reviewed By: username + password + Signature Type
  • Must match Perform By / Review Responsibility on the task plan header
  • Performed By signing clears reviewed-by details
  • Screen lists only checklists you created → reviewer uses Review screen

7. On Reviewed By sign

  • Regulated items with Repairs Needed checked per OPCKLREG
  • Equipment set back to operational when all are repaired / temp-repaired with follow-up
  • OPCKLFUP = ON → auto follow-up WOs or DM
  • Create from Checklist on → nonconformities / observations

8. Organization options

OPCKLREG N → resolution (+follow-up) needed P → blank resolution OK + follow-up OFF → no checks OCCLFLUP YES / WARNING / NO (follow-up w/o WO) OCFUTYPE DM | WO OCFUFPTP YES | NO CHCKLSEQ YES → renumber by WO Route

9. Review Operator Checklist

  • Shows all checklists NOT at system status Unfinished
  • Most fields protected; Status, Performed By, Reviewed By, Follow-up editable
  • Once Complete, no other system status allowed
  • Multi-select status change in list view; Status Authorization Matrix applies

10. Equipment tab

  • Operator Checklists tab on Assets, Positions, Systems, Locations
  • Read-only list for the header equipment
  • Double-click → read-only Checklist Items popup
  • Install param SHOWJOB enables the Job Selector

Flow

Equipment→ Task Plan→ Fill items→ Performed By→ Review→ Complete

Consultant tips

  1. One Default task plan per class
  2. Hide Reviewed By if review is separate
  3. Set OCFUTYPE before go-live

Key points

  • No WO needed to start
  • Reopen = today + yours only
  • OCCLFLUP check moves to Review
