Reservation Calendar Cheat sheet
Book pool, loaner and other equipment on a drag-and-drop calendar.

1. What it is

  • Request and reserve equipment on a calendar-style screen
  • Drag blocks to change start / end times, Outlook-style
  • Found under the Equipment menu
  • Extra Standalone (calendar) view per equipment

2. Screen Setup: Reservation Calendar tab

  • Defaults for the screen and its clones
  • Scheduler View: Minute (15 min) / Hour / Day
  • Block Duration for double-click creates (changes with view)
  • Working Start/End Times: outside hours greyed out
  • Popup Function: pick a copy of the details popup

3. Reservation types

TypeEquipment shownStatuses here
PoolMarked Reservable EquipmentRequest / Reserved / Cancelled
LoanerMarked Contract EquipmentRequest / Reserved / Cancelled
OtherAll other equipment + LocationsReserved / Cancelled
  • Other records are NOT shown on the Reservations screen

4. Screen layout

  • Equipment grid (left): Pool, Loaner or Other list
  • Scheduler grid (right): Minute, Hour or Day calendar
  • Filter equipment by type and class on Screen Setup tabs
  • Go To Day jumps to any date

5. Create a reservation

Double-click empty slot → Block Duration Click + drag + release → ends where mouse released ↓ Details popup → also creates a record on the Reservations screen (Pool/Loaner)

6. Modify & delete

  • Double-click block → edit times in popup
  • Drag the ends, or drag-drop within the row
  • Drop on another row = change equipment (popup opens if Org differs)
  • Right-click → Delete Event: removes block only, not the Reservations record

7. Who can edit

Calendar Owner (on equipment)Can edit
BlankOnly the Created user

*All EAM users

8. Private flag

  • Only the creating user sees the check box
  • For non-owners: popup won't open
  • Block description hidden
  • No drag / drop / edit

9. Transition times

  • Travel From / Travel To / Setup / Tear Down
  • Shown as grey shading outside the block
  • All Day = spans the whole day
  • Status colours set on System Codes

10. Calendar view

  • Double-click an equipment record to open it
  • Days = columns, time = rows
  • Only for Minute or Hour view
  • Same create / edit rules apply
  • WO, Project, Suppliers, E-Mail Recipients: info only

Flow

Screen Setup→ Pick equipment→ Drag a block→ Popup details→ Reservation

Consultant tips

  1. Set Calendar Owner first
  2. Colour statuses in System Codes
  3. Other type = calendar only

Key points

  • Delete Event ≠ delete record
  • Day view: working days, no hours
  • * owner = everyone edits
