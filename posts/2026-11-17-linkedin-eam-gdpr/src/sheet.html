GDPR: Report & Revoke Personal Data Cheat sheet
Find every record that names a person, then anonymise it safely with the nightly FORGETME job.

1. What it is

  • Reporting + auditing features that support EU GDPR compliance
  • For system admins who review and audit personnel data
  • GDPR also applies to non-EU companies processing EU residents' data

2. Personnel entities

  • Caller · Contact · Employee · Supervisor · User
  • Name, date of birth, address, phone, e-mail can identify a person
  • Person can ask to be removed at any time

3. GDPR Compliance reports

  • 5 reports, one per entity
  • Select the entity → run the report
  • Lists, table by table, every record holding that value
  • Shows Primary Key fields + Description (if the table has one)

5. Revoke button

  • Install parameter GDPROPTN = ON → Revoke shown on the 5 entity screens; otherwise hidden
  • Confirm: "permanently remove this record and all references… not reversible"
  • Yes → record written to R5FORGETME

7. Nightly FORGETME job

for each R5FORGETME row not C / E: 1 create new record (system-generated value) 2 replace all references → new record 3 mark new record Out of Service 4 delete the old record
  • eRecords are not impacted

8. Status & errors

CodeMeaning
SScheduled
PIn Progress
CCompleted
EIn Error → see Errors tab; set back to S to reprocess

9. GDPR Administration screen

  • Read only: no records created or inserted
  • Shows date marked, user who marked it, entity type, entity code, status
  • Errors tab holds messages for "E" records

10. Protected & overrides

  • Users that can't be revoked: *, R5, R5REQ, DATABRIDGEINTERNALUSER, INTERNALEAMUSER, CUSTOMCREATED, EAM-DOCUMOTOUSER
  • Employee * is also protected
  • US 21CFR11 overrides GDPR: R5ELECSIGN + _ARCHIVE keep full integrity

Flow

Request→ Compliance report→ Revoke→ R5FORGETME→ Nightly job→ C / E

Consultant tips

  1. Run the report before you revoke
  2. Keep GDPROPTN OFF until the process is agreed
  3. Check the Errors tab the next morning

Key points

  • Revocation is not reversible
  • Anonymise, don't break references
  • Read-only admin screen
