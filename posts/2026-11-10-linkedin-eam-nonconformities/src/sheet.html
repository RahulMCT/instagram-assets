Nonconformities Cheat sheet
Track defects that don't need a fix yet, watch them grow with observations, and re-inspect through PMs.

1. What it is

  • Track anomalies that don't need a fix yet: road crack, early pipe corrosion, wood rot
  • One nonconformity, many observations over time (Obs 1 Jan, Obs 2 Jul)
  • Equipment is required; Organization is specific
  • Status NCST: Open (editable) / Closed (protected, no re-inspection)

2. Where it lives

  • Nonconformities screen + Observation & Checklist tabs
  • Nonconformity Observations: one row per observation
  • Work Orders: Nonconformities tab (header UDFs) / Observations tab (obs UDFs)
  • Assets, Positions, Systems, Locations: Create Nonconformity button

3. Condition inputs

FieldEntitySample
SeveritySEVESevere / Serious / Minor
IntensityINTNLow / Average / High
Sizenumberarea or size
ImportanceIMPTPrimary / Secondary / Tertiary
  • Output: Condition Score, Condition Index, Next Inspection Date

4. Condition Score Matrix

Org RCM Project (else STPR default) 1) exact match on all entered fields 2) Severity + Intensity + Size 3) Severity + Intensity 4) Severity only
  • Size From/To ranges can't overlap
  • Condition Index = OBRI code CI; Re-Inspect After sets next date

5. Observation status (NOST)

StatusData
UnfinishedEditable
Request Approval / ApprovedProtected (Revision Control can unlock)
SkippedProtected, nothing changed
RepairEditable until WO completed
SupersededProtected, older approved

6. Types & defaults

  • Nonconformity Types: rot, corrosion, cracking...
  • General by default; unticked once linked to Material Type, EMRS or Part
  • Type defaults Severity, Class, Task Plan for Checklist
  • Part / VMRS codes default Material Type + Importance

7. Nonconformities Setup

  • Synchronize Header: At Approval / At Update / Never
  • Use Observation Status: Yes / No / Automatic
  • Auto Approve + Auto Skip Status at WO close (blank + Yes blocks closing)
  • Merge Restrictions: Unrestricted, Restricted, Similar Equipment/Type/Part
  • Create from Checklist: At Review Sign Off / WO Only / Never

8. Auto re-inspection

  • PM Schedules Equipment tab: Include Nonconformities + Due Nonconformities Only
  • Nonconformities tab = filters (empty = all of that equipment)
  • Generate WOs picks Open NCs on WO equipment, children and route
  • Due = Next Inspection Date (or override) <= WO Due Date or today

9. Buttons that matter

  • Create WO: new Repair observation linked to the WO
  • Merge Nonconformity: merged one closes, observations renumbered by Date Recorded
  • Create Capital Planning Request: misc cost added to material
  • Mass Acknowledge (mobile only): 50 on WO, 3 changed, 47 acknowledged

10. Built-in alert

Create Work Order for Nonconformities Status Open, Type set, Recommended Repair Date set Repair Date - LeadTime (14) <= today TypeHasStandardWO = YES (default)
  • No WO already created by the alert
  • NONCDAYS (999999) limits edits after WO close

Flow

Observe→ Score→ PM re-inspect→ Approve / Skip→ Repair WO

Consultant tips

  1. Build the matrix before go-live
  2. Pick one WO tab for users
  3. Brief inspectors on "Due only"

Key points

  • Track, don't fix (yet)
  • Observations show the trend
  • Closed = out of re-inspection
