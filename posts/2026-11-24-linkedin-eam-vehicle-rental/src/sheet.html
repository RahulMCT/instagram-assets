Vehicle Rental Cheat sheet
Request, approve, reserve and issue vehicles to customers, the car-rental way.

1. What it is

  • Request, reserve and rent out vehicles to customers, like a car rental service
  • Ask for a vehicle type (SUV, Sports car…) or one specific vehicle
  • Rented for a fixed time frame (rental → return)
  • Infor EAM Vehicle Rental brief, release 11.5

2. The three screens

ScreenWho / purpose
Customer Rental RequestRequestor creates the request
Review Customer Rental RequestsApprover / admin accepts or rejects
Customer RentalsAccepted rental is issued out

3. Customer Rental Request fields

  • Customer Rental Request: system-generated unique number
  • Description: required, names the request
  • Vehicle Type dropdown: list is set up by the user
  • Vehicle: optional specific unit
  • Rental and Return date/times = rental length
  • Details section: phone numbers, e-mail address
  • User defined + custom fields available

4. Send for approval

  • Save a draft and come back later
  • Ready? Change status to Request Approval
  • Request moves to Review Customer Rental Requests
  • After that, all fields are protected on the request

5. Accept / Reject install parameters

CRENACP → status on Accept (default: Reserved) CRENREJ → status on Reject (default: Cancelled)
  • Change the values to fit your status flow

6. Review screen behaviour

  • Records hyperlink to Customer Rental Request (double-click for details)
  • Reject Reason is always required (popup)
  • Use Reason for All: one reason for all selected records
  • Requestor sees rejections + reasons on the request screen

7. Customer Rentals changes

  • New Vehicle Type field
  • New Estimated Issue / Return date/times (create a request from here)
  • Status Unfinished renamed Reserved
  • Rental Template and Customer now optional
  • Invoicing + cost calculations can be opted out

8. Reports

ReportShows
Overdue Vehicle Issue Return ListLate pickups and returns
Vehicle Rental historyFull rental + return history per vehicle
  • Contract side: see the Contract Management whitepaper

Flow

Rental Request→ Request Approval→ Review→ Reserved / Cancelled→ Customer Rentals: issue→ Return

Consultant tips

  1. Set up the Vehicle Type list before go-live
  2. Agree CRENACP / CRENREJ values with the business
  3. Internal pools: skip invoicing and costs

Key points

  • Fields lock once sent for approval
  • Reject always needs a reason
  • Unfinished is now Reserved
