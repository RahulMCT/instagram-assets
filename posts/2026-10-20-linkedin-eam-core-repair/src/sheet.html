🔁 HxGN EAM Core Repair CHEAT SHEET
Repairable / rotable spares: return the broken core, repair it in-house or at a supplier, receive it back to stock. (Infor EAM 11.7 Core Repair brief)

1. What is a core?

  • A stocked part, used on equipment, that gets repaired when broken
  • a.k.a. repairable or rotable spare
  • Works for parts tracked by asset (qty always 1) and not tracked by asset
  • Setup: tick Track Cores on the Parts screen (also needed for Track by Asset parts)

2. Identify the core

  • Issue the new part → warning that a core return may follow (RRISSWAR)
  • Issue/Return Parts or WO Parts tab: Return + Core Return ✔
  • Child Equipment Replacement screen: core return / return / scrap
  • Unreturned Cores screen: issued qty > returned qty

3. Store quantities

4. Equipment Replacement tab

  • On the Work Orders screen; child must sit under the WO equipment
  • Allows substitute parts + condition filter
  • New asset inherits all parents, dependency, System/Assembly/Component Level + Component Location

5. Internal repair

  • WO Type Repairable Spare → Repair Parts tab
  • Part + Store + Qty to Repair → Assign Repair Details
  • Assets go To be repaired → In repair
  • Generate WOs: Generate WOs for Repairable Cores
  • Receive on Internal Repair Receipts (Qty Received / Scrapped, bin) and approve

6. External repair

  • Requisition line Type External Repair
  • Assign Repair Details only after the line is approved
  • Generate Requisitions: Generate External Repair Requisitions (grouped by Preferred Supplier)
  • PO approval → Repair issue; receive on PO Receipts

7. Parts › Repair Details tab

  • Per store (Stores tab record first)
  • Internal or External (drives auto-generation only)
  • Default Core Bin · Auto-Assign · Use Stock Method
  • Internal: WO Equipment, Department, Standard WO, Internal Repair Price
  • External: Preferred Supplier, Min Repair Qty, Lead Time

8. Install parameters

RRISSWARcore-return warning on issue

9a. Core flow

Issue new→Core Return→Qty to repair→WO / REQ→PO→Receipt→On hand

9b. Consultant tips

  1. One WO Equipment per part = repair cost history
  2. Fill Store on Repair Parts or auto-assign won't work
  3. Review Unreturned Cores regularly
  4. Compare repair cost vs buying new

9c. Key points

  • Track Cores ✔
  • Core Return ≠ Return
  • Approve receipts
