🔑 HxGN EAM Key Management CHEAT SHEET
Define physical keys and key rings, link them to locks and equipment, and track every issue and return to employees. (Infor EAM Key Management brief, 11.7 folder)

1. Key vs Ring

TypeUse
Key (default)One key: Access Level, Parent Key, Supplier, Key Type, Key Decode
RingGroups keys; key-detail fields cleared + protected
Key/Ring, Organization and Type lock after save.

2. Header fields

  • Status (protected): In Stock / Issued
  • Lost + Out of Service check boxes
  • Cabinet + Position = where it hangs
  • Supplier Key Number, Manufacturer

3. Issue a key

  • Enter Employee: Job Title + Department fill in
  • Save = Issue transaction
  • Issue Date = today, Status = Issued (I)
  • Issue Expiration Date unlocks

4. Return / reassign

  • Clear Employee + save = Return, Status In Stock (S)
  • Change Employee = Return (old) + Issue (new)
  • Holder Notes + dates are cleared
Expiration Date must be ≥ Issue Date.

5. Locks tab

  • Lock + Description, Location, Cylinder Number
  • Link Equipment: Dept + Workspace default from it
  • Lock may or may not belong to equipment
Not editable when Type = Ring.

6. Ring Keys tab

  • Add keys to a Ring record
  • Key gets Parent Ring + Holder Notes
  • Locked when Status = Issued
  • Ring holder change copies to all its keys

7. Copy Key popup

  • New Key + Description; copy Locks, Comments, Documents
  • Copy resets to In Stock, no holder, no Parent Ring
Copy Key is blocked for Rings.

8. Where keys show up

  • Transactions tab: read-only issue / return log
  • Keys tab on Assets, Positions, Systems, Facilities, Rooms, Vehicles...
  • Keys tab on Employees
  • Reports: Key List-Detail, Ring List-Detail

9a. Key lifecycle

Define key + lock→Add to Ring→Issue to Employee→Return / reassign

9b. Consultant tips

  1. Issue the Ring, not each key
  2. Always set an Issue Expiration Date for contractors
  3. Use Cabinet + Position for the key cabinet
  4. Audit with the Employees Keys tab at exit

9c. Key points

  • Save = transaction
  • Ring drives its keys
  • Lost flag ≠ return
