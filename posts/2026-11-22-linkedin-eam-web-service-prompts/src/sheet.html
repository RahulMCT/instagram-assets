Web Service Prompts Cheat sheet
Build your own data-entry screens from web services: one page, only the fields you need, saved in Process Group order.

1. What it is

  • Build your own screen from web services: pick only the fields you need
  • Several web services on one page (e.g. Add Asset + Comment + Structure)
  • Administration menu → Web Service Prompt screen (BSWSPM)
  • Enterprise Edition only (not Business); no Web Service Toolkit needed; no setup

2. Record View tab

  • Code + Description = screen name in the menu
  • Type: stand-alone screen or tab on screen (+ Parent Screen)
  • Save creates a Screens record of Class WSP
  • Out of Service hides it from lookups · cascade delete (blocked while in a user menu)
  • Right-click → Copy Web Service Prompt

3. Web Services tab

  • Find by Screen + Tab + Action (insert / update / delete) or type the name
  • Process Group = display order + save order; unique, default from INCRLINO
  • Controlling org field auto-added to Fields tab
  • Screen Section Title overrides e.g. MP0037_AddActivity_001 → "AddActivity"
  • BSCOMM for comments · Create Import Utility Template (Excel)

4. Fields tab: Field Type

TypeBehaviour
alphabetic / numeric / date / free format text / check boxDefaulted from the web service field
fixedFixed Data; hidden or protected only
computedSELECT run at save; hidden or protected
retrieved fieldKey value from an earlier Process Group
key fieldOnly for sync (update) / delete WS

5. Sequence rules

INCRLINO=10, WSPFSEQ=100 1st field PG 10 = 10 x 100 + 10 = 1010 2nd field PG 10 = 1010 + 10 = 1020
  • Sequence = tab order; Next Sequence = where cursor goes (1–99999999)
  • Must stay above previous and below next Process Group
  • Numeric with no Max Length → 24 characters

6. Computed & Query Code

SELECT sysdate FROM dual; SELECT per_mrc FROM r5personnel WHERE per_code = :1010;
  • :<sequence> references another prompt field
  • Lookups are not inherited: add a Query Code (not Inbox / KPI queries)
  • Mobile Query Code runs on local mobile tables only when offline

7. Smart field options

  • Retrieved field: Add Asset Equipment → asset code into Add Work Order (key fields only)
  • Unmapped Field: placeholder, never saved to the DB
  • Use Previous Value: defaults last entry into next record
  • Branching: If Data Is =, Pattern POOR, Go To 10
  • Pattern Match: . letter # digit _ alnum % string , OR ; THROUGH ! NOT

8. Retrieved Values tab

  • Tab out of Source seq → Query Code fills Destination seq
  • Destination sequence must be greater than Source
  • Needs Query Code, Mobile Query Code or both
  • Not a single value → lookup shown on Destination
  • Good for orgs + descriptions (e.g. Store → Store Org.)

9. Menu + run the screen

  • User Groups → Menus tab; tab type → "available for display" / "always displayed"
  • Strict tab order by Sequence; hidden / protected fields skipped
  • Save (= F10) submits every Process Group in order, then back to insert mode
  • Toolbar: Previous Screen, Save, Reset Screen, Help, Screen Designer; no Dataspy / Export / right-click

10. Update & delete prompts

  • Opens with key fields + controlling org only
  • Update: tab out → Query Web Service (GET) loads the record; keys protected
  • Delete: no GET; record deleted on tab out / save
  • Custom fields not available on delete web services

Flow

Record View→ Web Services→ Fields→ Retrieved Values→ User Group menu→ Test→ Screen Designer

Consultant tips

  1. Let the system assign Sequence / Next Sequence, then drag fields in Screen Designer
  2. Check box error? Switch it to alphabetic and enter + / -
  3. No warning for missing key / required fields: test it

Key points

  • Global, not org dependent
  • No tabs; not multi-language
  • R5WSPROMPTS, R5PROMPTWEBSERVICES, R5WSPROMPTFIELDS, R5WSPRETURNPROMPTS
