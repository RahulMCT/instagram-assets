📊 HxGN EAM Equipment Rankings CHEAT SHEET
Stop ranking criticality by gut feel: a survey + formulas turn answers into a score and an index on a schedule. (HxGN EAM 12.2 brief)

1. Five ranking types (RATP)

  • Reliability Index (also for Objectives)
  • Condition Index
  • Facility Condition Index
  • Risk Priority Index
  • Criticality Index
One asset can carry many rankings, e.g. a safety rank and an environment rank.

2. Survey Setup tab (tree)

  • Branches go max 3 levels below the top
  • Lowest level of each branch = question level
  • Answers: multiple choice (each has a Value) or Numeric / Integer with Min/Max
  • Non-question levels get a formula
  • Normalize Level when branches use different units

3. Three ways to answer

SourceHow
ManualRanking Survey tab
CalculatedQuery Code from the Queries screen
ChecklistAspect + Checklist Type; latest result on a completed WO

4. Calculated question query

SELECT number FROM table
WHERE equipment = :OBJECT
AND organization = :OBJECTORG
  • Must return 1 row, 1 column
  • Tick Query Option "Equipment Ranking"
  • :RANKINGLEVEL, :FROMPOINT, :TOPOINT also available

5. Formula roll-up

L1.1 = :L2.1 * 2 + 10
TOP = GREATEST(:L1.1, :L1.2 * 2)
+ ROUND(:L1.1 * 10 / :L1.2, 1)
A NULL query result makes the formula fail: wrap with COALESCE(:param, 0). A missing checklist result has no such fix.

6. Ranks tab: score → index

  • Min / Max Value → Ranking Index (entity OBRI)
  • Criticality Index type uses OBCR
  • Color + Icon drive the Linear Overview
  • No Ranks for Facility Condition Index
  • Track History: condition, risk priority, criticality only

7. Condition protocols

  • Condition Inspection (survey based)
  • Age, Usage
  • Decay Curve (Age / % of Age / Usage / % of Usage)
  • Score Start, End and Threshold = end of useful life
20-yr life, score 1→5, year 10:
1 + (5-1)/20*10 = 3
Correction to 2 → year 11 = 2.2

8. Rankings tab on the asset

  • Unlimited Reliability Indexes; only one Condition Index and one Facility Condition Index
  • Default one Reliability ranking shows on Record View
  • Lock Ranking Values stops recalculation
  • Out of Sync flag when setup changed later
  • A calculated Criticality overwrites a manual one

9. Recalculation + bulk

FeatureWhat it does
CALCRANK batch jobActivate on Job Setup. Picks unlocked records where Next Refresh ≤ today (or Refresh Every set, Next Refresh blank); sets Ranking Calculation Error and continues on failure
Refresh SequenceChildren = 1, parent = 2 when the parent score depends on children (blanks run first)
Batch Update Equipment Ranking ValuesPick by class / category / equipment + Include Children; Apply, Detach or Set as Default; calculate here only if no calculated or checklist questions
Objectives / Strategies / PoliciesOne ranking each, type Reliability Index; no checklist questions

10a. Setup flow

Queries + Decay Curves→Equipment Ranking + Type→Survey tree + formulas→Ranks tab→Attach to assets (batch)→CALCRANK

10b. Consultant tips

  1. Test each query returns 1 value
  2. COALESCE every calculated param
  3. Use Refresh Sequence for parent/child
  4. Small batches beat one big batch

10c. Key points

  • Same logic, same rank, every time
  • Scores refresh as data changes
  • Feeds RCM, risk and capital plans
